- 仓储方向仍缺可逐条核验的现行技术正文：粮温/湿度检查频次与点位、通风控温条件、害虫和霉变识别、药剂与熏蒸参数均不得据现有指南推断。

- 现有实验室来源适用资质认定或风险监测场景；对一般企业内部实验室的岗位要求不得自动外推。
