## 需要维护者手工验证

以下步骤涉及微信账号、真机、第二设备或主动断网，自动化不会代替维护者执行。截图和反馈只记录结果，不记录 OpenID、内部账号键、用户答案、token 或凭据。

1. **首次启动与游客模式**：在没有本小程序本地缓存的设备 B 首次打开，确认首先显示登录提示；点击“暂不登录”，完成一条易识别的游客学习记录，重新启动后确认不再重复提示。
2. **新账号与游客隔离**：在设备 A 记录当前游客统计、收藏和未完成练习；从“我的 -> 登录并同步”完成微信登录。确认账号侧为云端空白默认数据，且没有出现设备 A 或 B 的游客记录。
3. **同账号跨设备恢复**：设备 A 登录后修改一项资料或收藏并完成一组练习，等待“已同步”；设备 B 使用同一微信账号登录，确认资料、收藏、统计和练习状态与设备 A 云端状态一致。
4. **断网 outbox 重放**：账号模式下断开设备 B 网络，完成一次练习或收藏操作，确认显示“待同步”；恢复网络，确认最终显示“已同步”，退出并重新进入后数据仍存在。
5. **双设备 revision 冲突**：两台设备先同步到同一状态，然后同时断网；在两端对同一 revision 域作不同修改，例如分别变更收藏。先让设备 A 联网同步，再让设备 B 联网；确认设备 B 显示“已恢复云端记录”，最终采用设备 A 的云端结果而不是合并设备 B 的冲突写入。
6. **退出登录的两种选择**：账号模式断网后制造一项待同步写入，再点“账号与数据 -> 退出登录”。确认出现“继续重试/放弃并退出”；先选“继续重试”，确认网络仍不可用时保留账号状态，联网后可重试成功。再次登录并制造另一项离线写入，第二次选择“放弃并退出”，确认回到原游客数据，重新登录后被放弃的写入未出现在云端。
7. **清除学习数据中断恢复（当前阻断，勿执行）**：先补足两次明确确认并重新验证。修复后，账号侧产生一条练习记录，执行“清除学习数据”；首次调用会保留可恢复的清理状态并提示未完成。在完成重试前关闭小程序或断网，随后恢复网络并重新进入/重试，确认最终只清除练习、错题、收藏和未完成练习，资料及设置保留。
8. **永久注销中断重试（当前阻断，勿执行）**：先补足两次明确确认并重新验证。修复后，使用可删除的验收数据执行“永久注销账号”，在无网络时确认显示“账号注销未完成”且仍保留恢复状态；恢复网络后再次完成两次确认，等待成功提示，再确认客户端回到游客数据。由本记录后续的只读数据库计数核对账号、进度和练习记录均已删除。该步骤会永久删除验收账号的云端学习数据，必须由维护者在操作时主动确认。
