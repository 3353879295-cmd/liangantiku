# 启动与使用体验优化

修改位于当前微信开发者工具项目 `.worktrees/warehouse-question-classification/miniapp`。开发者工具当日日志和运行时均已确认该路径。本轮为本地优化，版本号仍为 1.1.2，未上传开发版本、提交审核或发布，也未部署云函数。

## 完成内容

- 启动不再解压并转换全部 7,428 道题。按两个职业、五个等级生成十个压缩分片，首页直接读取题量元数据，开始练习时才加载所需分片。并发查询复用加载结果，失败后可重试。
- 练习路由通过轻量目录元数据校验，实际题目仍由 Repository 确认。题目 ID、内容、顺序、职业与等级保持一致，继续支持离线题库。
- 首页区分加载中、读取失败与题库待补充，失败提供重试；修复显示“查看结果”却进入题库目录的入口问题；随机练习准备过程中有明确提示。
- 错题与收藏页保留完整筛选数据，首屏显示 20 道题，触底或点击按钮后增量追加，开始练习仍使用完整筛选结果。返回页面刷新收藏与错题，补齐技师、高级技师筛选，扩大筛选、解析与掌握操作的触控区域并适配底部安全区。
- 答题卡和结果页区分恢复中、恢复失败与无练习，支持重试、防止并发恢复；页面卸载后不回写或继续提交练习。
- 实操关联题加载和练习入口防重复点击；导航失败保留已创建会话，成功跳转后再次练习会新建会话，关联题变化也会使旧复用失效。
- 个人中心同步重试防并发，失败可再次重试，退出页面后不再刷新旧页面；移除过时的 0.1.0 展示文案。
- 将仅实操详情使用的 50,574 字节主图移入 auxiliary 分包，清理首页已不使用的目录样式。

## 本地性能对照

使用同一台电脑、Node.js、esbuild 打包方式、内存存储适配和七次独立进程，比较改动前后的 `appServices` 初始化与默认仓储初级题库读取。下表为中位数，包含模块解析与业务初始化，不包含微信网络下载、基础库启动、页面渲染或真机开屏时间。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 服务初始化 | 76.64 ms | 15.61 ms |
| 初始化并读取首页题量 | 77.24 ms | 15.65 ms |
| 初始化并首次读取 953 道仓储初级题 | 77.49 ms | 26.71 ms |
| 初始化堆内存增量 | 21.42 MiB | 4.03 MiB |

首页相关初始化基准约减少 80%，初始化堆增量约减少 81%；不能将这些数字直接当作真机打开速度的提升比例。
