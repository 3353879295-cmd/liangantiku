# 提交后答题卡与错题解析空白修复

## 现象与根因

- 手机完成练习并提交后，结果页仍显示成绩，但打开答题卡或本次错题解析后没有内容。
- 提交后的试卷保存在本机，云同步只保存进行中的练习，因此提交会发送 `saveActiveSession(null)`。
- 同步完成后，`CloudSyncService.saveSnapshot()` 用云端空会话覆盖本地已提交试卷；运行时检测到持久化记录变化，也清掉内存会话。
- 结果页保留了自己的成绩快照，而答题卡及本次错题列表重新读取全局会话，因此同时出现空白。
- 错题列表的空状态还错误地跟随“加载更多”的 `wx:else`，题数不足一页时即使有题，也显示“没有错题”。

## 本次范围

- 在普通同账号同步中保留本地已提交试卷及该试卷的已计分标记，使答题卡、错题解析和再次进入结果页正常读取。
- 云端有新的进行中练习、账号切换或学习数据清除时，仍接受相应的新状态。
- 错题列表仅在实际没有题目时显示空状态。
- 素材制作说明移到 `docs/miniapp-practical-assets.md`，原 `assets/README.md` 保留链接；完整来源记录保留，避免长文占用主包体积。
- 沿用 `.worktrees/warehouse-question-classification/miniapp`，保留所有既有未提交修改。
