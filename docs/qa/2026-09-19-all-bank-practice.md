# 全题库顺序练习验证

日期：2026-09-19。项目为微信开发者工具登记的 `warehouse-question-classification/miniapp`。

## 行为

- 教材目录题库卡片的状态标识改为可点击的“全部刷题／继续刷题”，显示当前题量、完成数量和每组 20 题提示。
- 按当前职业、等级的题库顺序选取未完成题，按题目 ID 去重；每组最多 20 题，结果页可继续下一组。
- 每个证书、游客和账号分别保留当前顺序组的轻量备份，其他练习覆盖活动会话后仍可恢复；恢复时定位下一道未答题。题库删除题目时保留其余可用题的作答。
- 未答题不会因提前结束本组而变为已完成，也不会进入错题和成绩统计；零作答结束不发送云端不接受的空练习记录。刷完整个题库后停止，不自动循环。
- 快速切换题库或练习方式时，过期启动不能覆盖新练习；加载期间返回会取消对应请求，不产生未开始的顺序备份。
- 沿用职业等级分片的懒解压和缓存；一次只向答题视图发送当前题，答题卡最多显示当前组 20 个位置。没有拆成每题一次网络请求。
