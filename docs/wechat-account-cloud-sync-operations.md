## 微信头像上线闸门（云函数已更新，开发者工具头像流程已验收）

微信头像会新增 `account-avatars/<账号键>/<随机对象名>.<扩展名>` 云存储对象，并由小程序客户端上传、由 `accountSync` 记录归属及在注销时分批删除。该能力涉及新的个人信息存储、云存储写入和权限变化，不在 2026-09-03 的既有授权范围内；修改线上配置或部署前必须重新取得明确确认。

上线前应先只读核对当前云存储对象和权限，再评审并配置最小权限的自定义安全规则。当前仓库没有其他客户端云存储用途时，候选规则为：

```json
{
  "read": "auth != null && resource.openid == auth.openid && (/^account-avatars\\/[a-f0-9]{64}\\/[a-z0-9-]{8,128}\\.jpg$/.test(resource.path) || /^account-avatars\\/[a-f0-9]{64}\\/[a-z0-9-]{8,128}\\.jpeg$/.test(resource.path) || /^account-avatars\\/[a-f0-9]{64}\\/[a-z0-9-]{8,128}\\.png$/.test(resource.path) || /^account-avatars\\/[a-f0-9]{64}\\/[a-z0-9-]{8,128}\\.webp$/.test(resource.path))",
  "write": "auth != null && resource.openid == auth.openid && resource.size <= 5242880 && (/^account-avatars\\/[a-f0-9]{64}\\/[a-z0-9-]{8,128}\\.jpg$/.test(resource.path) || /^account-avatars\\/[a-f0-9]{64}\\/[a-z0-9-]{8,128}\\.jpeg$/.test(resource.path) || /^account-avatars\\/[a-f0-9]{64}\\/[a-z0-9-]{8,128}\\.png$/.test(resource.path) || /^account-avatars\\/[a-f0-9]{64}\\/[a-z0-9-]{8,128}\\.webp$/.test(resource.path))"
}
```

该规则会作用于整个云存储桶；若只读核对发现已有其他文件用途，不得直接套用，应把其他已批准路径的规则一并纳入评审。云函数使用服务端权限执行注销清理，不依赖客户端规则放宽权限。

`resource.openid == auth.openid` 约束的是文件创建者，安全规则本身不能计算并核对路径中的派生账号键；路径与当前账号的绑定由 `accountSync` 在保存资料时再次严格校验。被篡改的客户端仍可能创建“归自己所有但未绑定账号”的对象，因此上线前还应确认云存储配额与滥用监控；如果威胁模型要求从源头禁止这类对象，必须改为服务端受控上传或一次性签名方案，不能仅依赖上述客户端直传规则。

发布顺序必须是：部署新版 `accountSync` 云函数并验证其快照已返回账号专属上传前缀；配置并验证云存储规则；在开发者工具与真机完成头像选择、跨设备显示、断网重试、双设备冲突、放弃待同步退出和注销清理；最后才发布小程序客户端。客户端现已兼容缺少上传前缀的旧快照：普通登录和学习数据恢复正常，仅头像上传被阻止并提示“头像服务正在升级，请稍后再试”。该兼容修复不代表头像云端能力已经上线；显式非法前缀仍会被拒绝。

## 故障处理与回滚

- 集合或索引创建失败：停止后续步骤，保留已创建资源，记录不含敏感信息的错误码；核对环境和权限后从失败步骤重试。
- 云函数部署失败：不改动集合权限，不发布客户端；修复本地代码并重新通过 `npm run verify` 后再部署。
- 同名资源已存在：不得删除、覆盖或改变权限；先确认其所有者、结构、索引和数据用途。
- 客户端同步失败：账号本地缓存和 outbox 保持可恢复，游客数据不受影响；使用稳定错误码定位，禁止直接手工修改用户文档。
- 客户端收到 `REVISION_CONFLICT`：先验证云端账号归属并获取最新修订，保留未确认命令，按正常队列自动重试，每条操作最多三轮；持续失败保留记录，等待后续前台或网络恢复。答卷由服务端会话 ID 去重，设置只合并本机修改字段。不得手动清空队列、改修订号、移除暂停标记或伪造成功；历史暂停保护与旧客户端行为见 `qa/2026-09-08-account-sync-diagnostics.md`，当前行为与真实恢复结论见 `qa/2026-09-19-automatic-account-recovery.md`。
- 新部署版本异常：停止发布客户端，回退到上一已验证的云函数版本。若这是首次部署，则暂停 `accountSync` 使用但保留集合数据，不以删除集合方式回滚。
- 注销或清除中断：重复调用原动作继续状态机，完成前不得向用户显示成功，也不得手工跳过删除阶段。

任何涉及删除集合、删除线上数据、改变客户端权限或计费的动作都不属于本清单，必须另行评审并取得明确确认。
