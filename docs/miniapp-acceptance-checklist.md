## 微信开发者工具

首次运行需先登录微信开发者工具，再导入仓库中的 `miniapp/` 目录。

- [ ] 选择“工具 → 构建 npm”，项目中可解析 TDesign 组件。
- [ ] 点击“编译”，控制台无错误、无未处理 Promise 警告。
- [ ] 四个底部入口：首页、题库、实操、我的，均可正常切换。
- [ ] 首页统计来自本地记录；开始练习后退出，再进入可续答。
- [ ] 六个证书分类都能开始章节、顺序、随机和模拟练习。
- [ ] 单选、判断可提交；普通练习即时显示答案、解析、易错提示和依据。
- [ ] 多选在选择多个选项后提交，选项顺序不影响判分。
- [ ] 模拟考试答题时不显示解析，交卷后才进入结果页。
- [ ] 答题卡能区分已答、未答和当前题，并能跳转到指定题。
- [ ] 结果页显示分数、正确率、用时、薄弱模块，并能重练错题。
- [ ] 错题、收藏、掌握筛选和空状态正常；重复进入结果页不会重复累计错题。
- [ ] 12 张实操技能卡均可打开，步骤、安全提醒、常见错误和依据完整。
- [ ] “我的”可切换目标证书和每日目标；清空数据需二次确认。
- [ ] iPhone 常见尺寸下无横向溢出，长题干和大字号下仍可操作。

## 当前本机验收说明

自动化项目已全部通过。微信开发者工具日志显示本机登录凭证失效（`access_token missing`），因此上面的模拟器项目必须在扫码重新登录后手动勾选；这不是工程编译错误。上传或发布前还需替换为有权限的正式 AppID，并按实际考试大纲继续扩充、复核题量。
