# 粮安题库微信账号与云端学习同步设计

日期：2026-09-02

状态：用户已确认设计

正式 AppID：`wx84ecacec08ca162c`

目标云环境：`cloud1-d2gglad830c91db10`

## 1. 目标

为粮安题库小程序增加完整的微信账号能力，让用户首次进入时可以选择微信登录或暂不登录，并让登录用户的学习记录、错题、收藏、未完成练习和设置保存到微信云开发，在其他设备登录同一微信账号后恢复。

账号登录只识别当前微信用户，不获取手机号、微信昵称或微信头像。小程序继续使用现有昵称和内置头像编辑能力，并把登录用户的资料保存到云端。

## 2. 已确认的产品规则

- 首次进入小程序时显示登录引导，提供“微信登录”和“暂不登录”。
- 用户选择游客后可以继续浏览和答题；以后启动不再重复弹出登录引导。
- “我的”页面持续向游客提供“登录并同步”入口。
- 登录后以云端数据为唯一真源，不上传或合并登录前的本机游客数据。
- 新账号云端没有数据时创建空白档案，也不导入本机游客数据。
- 登录用户再次启动时自动恢复云端账号，不重复询问。
- 退出登录只清除本机账号状态并恢复该设备的游客档案，云端数据继续保留。
- 注销账号永久删除该用户全部云端资料、进度和练习记录，然后切回游客模式。
- 登录账号与游客使用完全独立的本地缓存和待同步队列。

## 3. 非目标

- 不绑定手机号、邮箱或密码。
- 不获取微信昵称、微信头像或通讯录信息。
- 不把游客数据升级、复制或合并到登录账号。
- 不建设网页端账号系统或独立业务服务器。
- 不在小程序中保存 AppSecret、OpenID、session key 或云端固定密钥。
- 不在本次工作中修改云开发套餐、自动续费、超额付费或其他计费设置。
- 不增加排行榜、社交关系或管理员用户后台。

## 4. 总体架构

采用“小程序页面 -> 账号与同步服务 -> `accountSync` 云函数 -> 用户数据集合”的结构。

```text
首次进入页 / 我的页 / 现有答题页面
                 |
       AuthService + ProgressService
                 |
       CloudSyncService + SyncOutbox
                 |
         accountSync 云函数
                 |
 user_accounts / user_progress / user_practice_records
```

模块职责：

- `AuthService` 管理 `checking`、`guest`、`authenticated` 和 `error` 登录状态，以及首次选择、自动恢复、退出和注销流程。
- `ProgressService` 继续管理答题、错题、收藏、统计和设置等领域行为，避免页面直接理解云端协议。
- `CloudSyncService` 把登录用户的领域变更转换为云函数命令，串行执行、处理版本冲突并刷新云端快照。
- `SyncOutbox` 只保存登录期间产生但尚未确认写入云端的命令；它不是游客数据，也不用于首次登录合并。
- `accountSync` 云函数从可信微信上下文获取当前用户身份，完成参数校验、所有权校验、事务、幂等和数据删除。
- 三个用户集合不允许小程序客户端直接读写。

## 5. 启动与登录流程

### 5.1 首次进入

新增独立的账号进入页，并将其作为 `app.json` 中的首个页面。页面完成云开发初始化和本地登录偏好检查。

本地登录偏好有三个值：

- `undecided`：从未选择，显示登录引导。
- `guest`：直接进入游客模式，不再次弹窗。
- `account`：自动调用 `accountSync.bootstrap` 恢复云端账号。

点击“微信登录”时才调用账号云函数。云函数根据调用上下文识别用户、创建或加载账号，前端不需要手机号、密码或自定义 token。

点击“暂不登录”时保存 `guest` 偏好并进入首页。游客可以浏览和答题，但“我的”页面明确显示“游客记录仅保存在本机，登录后以云端数据为准”。

### 5.2 已登录启动

登录偏好为 `account` 时，进入页显示简短加载状态并调用 `bootstrap`：

1. 如果存在尚未完成的账号同步命令，先按其原始云端版本尝试重放。
2. 重放成功后获取最新云端快照。
3. 如果版本冲突，放弃冲突命令，以云端快照覆盖账号缓存并提示用户。
4. 如果网络失败，保留账号缓存和待同步队列，但不把游客数据当作账号数据；页面提供重试和临时进入游客模式。

临时进入游客模式不会改变持久化的 `account` 偏好，下次启动仍尝试恢复账号。

### 5.3 退出登录

退出前先尝试发送待同步命令：

- 全部成功时清除账号缓存和账号待同步队列，保留云端账号，切换到该设备原有游客档案。
- 仍有失败时明确告知存在未同步数据，让用户选择继续重试或放弃未同步数据后退出，不静默丢弃。

### 5.4 注销账号

注销入口位于“我的 -> 账号与数据”，与退出登录分开。二次确认文案必须明确说明云端学习记录永久删除且无法恢复。

注销采用幂等的分批流程：

1. 云端把账号标记为 `deleting`，拒绝新的学习数据写入。
2. 分批删除 `user_practice_records`。
3. 删除 `user_progress`。
4. 最后删除 `user_accounts`。
5. 云端确认全部完成后，客户端才清除本机账号缓存并切回游客模式。

任一步失败都可以重新调用注销动作继续完成，不会恢复为可写账号，也不会提前声称删除成功。

## 6. 本地数据隔离与升级

现有本地键 `grain-practice:progress` 在功能升级后被迁移为游客档案，不能作为登录账号的初始化输入。

使用以下独立存储边界：

- `grain-practice:auth-preference`：首次选择和自动恢复偏好。
- `grain-practice:guest-progress`：游客学习数据。
- `grain-practice:account-cache`：当前登录账号从云端获取的页面快照。
- `grain-practice:account-outbox`：当前账号尚未完成的同步命令。
- `grain-practice:progress:recovery-backup`：保留现有损坏数据恢复机制。

旧键迁移必须可重复执行。迁移成功后，原数据只进入游客档案；登录后无论云端是否已有记录，都不得读取游客档案作为账号数据。

## 7. 云端数据模型

云端使用三个集合。所有字段采用稳定的 `snake_case`，每份文档包含 `schema_version`，时间使用服务端时间。

云函数以 `SHA-256(AppID + ":" + OpenID)` 生成内部 `account_key`。OpenID 和 `account_key` 都不返回客户端，不写业务日志。

### 7.1 `user_accounts`

每个微信用户一份账号文档：

| 字段 | 含义 |
| --- | --- |
| `_id` | `account_<account_key>` |
| `schema_version` | 账号结构版本，第一版为 `1` |
| `status` | `active` 或 `deleting` |
| `learning_clear_state` | `idle` 或 `clearing`，用于可重试地清除学习数据 |
| `revision` | 资料与设置的乐观锁版本 |
| `nickname` | 小程序内昵称，最多 12 个字符 |
| `avatar_url` | 白名单中的本地内置头像路径或空字符串 |
| `selected_certificate_key` | 当前职业等级 |
| `daily_goal` | 每日目标 |
| `answer_theme` | `light` 或 `night` |
| `answer_reveal_mode` | `immediate` 或 `deferred` |
| `created_at` | 创建时间 |
| `updated_at` | 最近更新时间 |

新账号使用当前小程序默认资料和设置，不能读取游客偏好作为默认值。

### 7.2 `user_progress`

每个微信用户一份当前学习状态文档：

| 字段 | 含义 |
| --- | --- |
| `_id` | `progress_<account_key>` |
| `schema_version` | 进度结构版本，第一版为 `1` |
| `revision` | 学习数据乐观锁版本 |
| `summary` | 累计答题、正确数、总时长和首次答题日期 |
| `question_totals` | 各题累计次数和正确次数 |
| `wrong_questions` | 错题次数、首次/最近错题日期和掌握状态 |
| `favorites` | 收藏题目及收藏时间 |
| `daily_totals` | 按日期聚合的答题、正确数和时长 |
| `recent_question_ids` | 最多 100 个最近做题 ID，用于现有去重逻辑 |
| `active_session` | 最新未完成练习或空值 |
| `updated_at` | 最近更新时间 |

页面需要的累计统计由云端聚合字段直接提供，不在启动时下载全部历史记录重新计算。

### 7.3 `user_practice_records`

每次提交练习一份不可变记录：

| 字段 | 含义 |
| --- | --- |
| `_id` | `record_<SHA-256(account_key + ":" + session_id)>` |
| `schema_version` | 练习记录结构版本，第一版为 `1` |
| `account_key` | 仅供云函数查询和注销清理 |
| `session_id` | 客户端生成的稳定练习 ID |
| `mode` | 练习模式 |
| `answers` | 本次题目、正误、耗时和答题日期 |
| `answered` | 本次答题数 |
| `correct` | 本次正确数 |
| `duration_ms` | 本次总时长 |
| `submitted_at` | 云端提交时间 |

相同账号与 `session_id` 只能生成同一 `_id`，重复调用返回既有结果，不重复增加统计。

为 `user_practice_records` 建立 `account_key + submitted_at` 索引，支持账号注销分批删除和后续历史查询。其他两个集合按确定 `_id` 读取，不增加非必要索引。

## 8. `accountSync` 云函数接口

云函数只接受白名单动作，不接受客户端提供 OpenID、账号键、任意数据库条件或任意字段路径。

### 8.1 `bootstrap`

创建或加载账号，返回资料、设置、进度快照、两个当前版本号和云端同步时间。响应不包含 OpenID、account key、数据库文档 ID 或底层错误。

### 8.2 `updateProfile`

保存昵称和内置头像路径。请求携带账号资料 `expectedRevision`；版本不一致时返回冲突，不覆盖云端。

### 8.3 `updatePreferences`

保存职业等级、每日目标、主题和答题显示方式，使用账号资料版本号校验。

### 8.4 `saveActiveSession`

保存最新未完成练习，使用进度版本号校验。同步队列只保留尚未发送的最新会话状态，避免每次选择答案都产生独立云调用。

### 8.5 `recordPractice`

提交完成练习。云函数在事务中完成以下动作：

1. 校验 `session_id`、练习模式、题目 ID、日期、正误和耗时。
2. 检查幂等练习记录是否存在。
3. 校验进度版本号。
4. 创建不可变练习记录。
5. 更新累计统计、题目统计、错题、每日统计和最近题目。
6. 清除与本次练习对应的未完成会话。
7. 增加进度版本号并返回最新快照。

### 8.6 `setFavorite` 与 `markMastered`

客户端发送最终目标状态而不是“切换”指令，避免重试时反向执行。两个动作均使用进度版本号校验。

### 8.7 `clearLearningData`

清除进度和练习记录但保留账号资料与设置。云函数先把 `user_accounts.learning_clear_state` 设为 `clearing`，此时拒绝新的学习数据写入；随后分批删除练习记录、重置进度文档，最后把状态恢复为 `idle` 并返回空白进度快照。重复调用从尚未完成的阶段继续执行。

### 8.8 `deleteAccount`

执行第 5.4 节的幂等分批注销，响应返回 `done` 和剩余阶段。客户端重复调用直至 `done: true`。

稳定错误码：

- `INVALID_REQUEST`
- `REVISION_CONFLICT`
- `SCHEMA_INCOMPATIBLE`
- `ACCOUNT_DELETING`
- `ACCOUNT_SYNC_UNAVAILABLE`

返回给用户的消息使用简明中文。数据库错误、堆栈、OpenID、账号键、环境信息和原始平台错误不返回客户端。

## 9. 同步与冲突规则

登录状态下，页面先更新账号缓存，再由串行队列发送命令，以保持答题交互流畅。缓存是云端快照与待确认命令的本地投影，不是另一个可参与首次登录合并的数据源。

同步队列遵循以下规则：

- 一次只发送一个命令。
- 每个命令保存创建时的 `expectedRevision`。
- 尚未发送的资料、设置和未完成会话命令只保留最新目标状态。
- 已提交练习命令不能合并，通过稳定 `session_id` 保证幂等。
- 网络失败使用有上限的退避重试，并在“我的”页面显示待同步或同步失败。
- 小程序回到前台和网络恢复时重试；不无限高频调用。
- `REVISION_CONFLICT` 时停止队列、获取云端快照、放弃冲突命令并提示“数据已在其他设备更新，已恢复云端记录”。
- 用户手动点击“重试同步”时复用同一命令 ID，不创建重复写入。

游客模式不创建账号同步命令，也不调用用户数据云函数。

## 10. 页面设计

### 10.1 首次进入页

页面沿用现有粮安题库的绿色主题和轻量视觉风格。

- 标题：`登录粮安题库`
- 说明：`登录后可跨设备同步学习记录、错题、收藏和设置。`
- 主按钮：`微信登录`
- 次按钮：`暂不登录`
- 加载状态：`正在恢复云端学习记录…`
- 登录失败操作：`重新登录`、`以游客身份进入`

### 10.2 “我的”页面

游客状态：

- 显示“当前为游客”。
- 说明“记录仅保存在本机，登录后以云端数据为准”。
- 显示“登录并同步”按钮。

已登录状态：

- 显示小程序昵称、内置头像和证书。
- 显示最近同步时间和 `同步中`、`待同步`、`同步失败` 状态。
- 同步失败时显示“重试同步”。
- 提供“账号与数据”入口，其中包含退出登录和注销账号。

编辑资料页继续使用现有昵称输入与四个内置头像，不调用微信用户资料接口。游客保存到游客档案；已登录用户通过账号同步接口保存到云端。

## 11. 安全与隐私

- 小程序使用明确的云环境 ID 初始化 `wx.cloud`。
- 云函数通过可信调用上下文识别当前微信用户，不相信客户端传入的身份字段。
- OpenID、account key、session key、AppSecret 和固定云密钥不进入小程序包、客户端缓存、响应或业务日志。
- `user_accounts`、`user_progress` 和 `user_practice_records` 的客户端权限均设为“无权限”。
- 云函数校验 action、结构版本、版本号、枚举、字符串长度、数组数量、数值范围、日期和题目 ID 格式。
- 云函数限制单次练习题数、注销分页大小和响应体大小。
- 日志只记录请求追踪 ID、动作、稳定错误码、耗时和结果状态，不记录用户答案或身份标识。
- 注销和清除数据必须二次确认；删除成功前不得清除唯一的本机恢复信息或向用户显示成功。

## 12. 错误与恢复

- 首次登录失败：保留在进入页，提供重试和游客入口。
- 自动恢复失败：不使用游客数据冒充账号数据，保留账号缓存和队列，显示重试或临时游客入口。
- 后台同步失败：不打断当前答题，保留命令并显示状态。
- 云端返回非法数据：拒绝覆盖有效缓存，记录脱敏错误并显示重试。
- 结构版本不兼容：停止写入，提示用户更新小程序。
- 注销中断：账号保持 `deleting`，再次调用从未完成阶段继续。
- 清除学习数据中断：保留清理状态，禁止在旧统计上继续写入，完成后返回空白进度。

## 13. 测试方案

### 13.1 领域与存储测试

- 旧 `grain-practice:progress` 只迁移到游客档案。
- 游客、账号缓存和账号待同步队列互相隔离。
- 新账号空白云端档案不读取游客数据。
- 登录、自动恢复、临时游客、退出和重新登录状态转换正确。
- 退出时待同步失败必须取得明确选择后才能丢弃。

### 13.2 同步测试

- 命令串行执行并持久化恢复。
- 资料、设置和未完成练习的未发送命令正确合并为最新目标状态。
- 完成练习不合并，重复 `session_id` 不重复统计。
- 临时网络失败按上限重试，恢复网络后继续。
- 版本冲突停止队列、加载云端并产生用户提示。
- 游客模式不调用账号云函数。

### 13.3 云函数测试

- 每个动作只操作调用者对应的账号键。
- 客户端伪造的 OpenID、账号键和任意字段被拒绝。
- 非法枚举、长度、数量、日期、题目 ID、负数耗时和结构版本被拒绝。
- `recordPractice` 在事务中幂等更新记录和统计。
- 收藏和掌握状态重试不会反向切换。
- 注销及清除学习数据可分批重试并最终删除完整。
- 错误响应不包含堆栈、数据库错误、OpenID 或环境信息。

### 13.4 页面与回归测试

- 首次进入页覆盖未选择、加载、失败和两种选择。
- “我的”页面覆盖游客、已登录、同步中、待同步和失败状态。
