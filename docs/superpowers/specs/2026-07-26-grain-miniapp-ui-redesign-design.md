# 粮安题库微信小程序 UI 重设计规格

**状态：** 视觉方向已确认，待规格复核  
**日期：** 2026-07-26  
**实施平台：** 原生微信小程序 + TypeScript + WXML/WXSS

## 1. 重设计目标

本次重设计在保留现有题库、组卷、评分、进度、错题和收藏业务能力的前提下，重构小程序的信息架构、视觉体系和答题交互。

核心目标：

1. 首页承担题库选择和学习入口，不再设置重复的“题库”底部导航。
2. 底部导航只保留“首页、实操、我的”三个入口。
3. 题库围绕《粮油仓储管理员（第二版）》目录组织，质检员继续作为独立职业模块。
4. 形成统一的 Apple 式奶绿色视觉体系，减少模板感和 AI 风格装饰。
5. 固化答题选项、解析、收藏、夜间模式和异常状态的交互规则。
6. 在不破坏现有领域服务和本地数据的前提下，按组件和主题令牌重构界面。

## 2. 本轮范围与非目标

### 2.1 本轮范围

- 重构首页、实操、我的三个主导航页面。
- 重构教材目录、随机练习设置、模拟考试说明、答题、答题卡、结果、错题本、收藏试题、实操详情、学习报告、编辑资料和学习设置等二级页面。
- 增加统一二级页返回按钮。
- 增加答题页夜间护眼模式。
- 增加收藏、选择选项等轻量动效。
- 统一语义化图标、空状态、加载状态、网络异常和题目纠错反馈。
- 保留本地优先和离线可用能力。

### 2.2 非目标

- 本轮不实现真实微信支付、会员后端或权益校验；会员入口和会员中心只完成界面与路由占位。
- 本轮不新增登录、云同步、排行榜、社区或 AI 出题。
- 本轮不凭空补齐技师、高级技师正式题目；没有数据时明确显示“待补充”。
- 本轮不修改题库审核和 JSONL 发布流水线的业务规则。

## 3. 信息架构

### 3.1 底部导航

底部导航固定为：

1. **首页**
2. **实操**
3. **我的**

原“题库”不再作为底部导航。现有 `pages/library` 可保留为教材目录二级路由或兼容跳转页，但不得继续出现在 `tabBar`。

### 3.2 页面层级

主导航页：

- `pages/home/index`
- `pages/practical/index`
- `pages/profile/index`

二级页：

- 教材目录
- 章节详情
- 随机练习设置
- 模拟考试说明
- 答题
- 答题卡
- 结果与解析
- 错题本
- 收藏试题
- 实操详情
- 学习报告
- 会员中心
- 编辑资料
- 学习设置

所有二级页左上角使用统一返回按钮。返回优先调用页面栈；没有可返回页面时回到来源主导航页。

## 4. 职业与等级

### 4.1 职业

题库先选择职业，再选择等级：

- 粮油仓储管理员
- 粮油质量检验员

质检员保持独立职业模块，不并入仓储管理员教材目录。

### 4.2 等级

界面展示五个等级：

1. 初级
2. 中级
3. 高级
4. 技师
5. 高级技师

现有正式题库只覆盖前三个等级时，技师和高级技师显示“待补充”。待补充等级可查看说明，但不能进入空练习会话。

领域类型需要能够表达五个等级；“是否有可用题库”是独立可用性状态，不能继续用只包含三个等级的类型暗示界面只支持三级。

### 4.3 选择方式

首页使用两阶段选择卡：

1. 先选择职业。
2. 再选择五个等级。

切换后同步更新：

- 当前题库标题
- 教材目录
- 章节进度
- 最近练习
- 错题和收藏筛选条件

不再展示无实际用途的“当前证书”板块。

## 5. 首页

首页从上到下为：

1. 用户信息栏：头像、昵称、备考天数、会员入口。
2. 页面主标题“粮安题库”。
3. 继续上次练习卡。
4. 职业与等级选择卡。
5. 开始学习功能区。
6. 与当前职业和等级联动的教材目录摘要。
7. 最近刷题记录。

开始学习功能区包含：

- 章节刷题
- 随机练习
- 模拟考试
- 错题本
- 收藏试题

“模拟考场”统一改名为“模拟考试”。

## 6. 教材目录

仓储管理员目录按《粮油仓储管理员（第二版）》组织。

目录卡规则：

- 章节编号显示 `1、2、3`，不使用 `01、02、03`。
- 数字使用圆润字形和柠绿色圆角块。
- 卡片显示章节名称、小节数、题目数、完成度和进度条。
- 点击章节进入章节详情，再选择具体小节开始练习。
- 页面只显示当前职业和等级对应的目录。

初级仓储管理员至少覆盖：

- 第一部分 基础知识
  - 第一章 职业道德
  - 第二章 基础知识
- 第二部分 初级粮油仓储管理员
  - 第三章 粮油出入库作业
  - 第四章 粮情检查
  - 第五章 粮情控制

中级、高级按教材目录分别呈现，不把其他等级章节混入当前目录。

## 7. 实操

### 7.1 实操首页

实操技能按职业分组，卡片包括：

- 语义化线性图标
- 技能名称
- 简短说明
- 进入详情的箭头

禁止使用“仓、温、虫、检”等文字代替图标。

推荐语义图标：

- 粮油出入库：仓房或筒仓
- 粮温检查：温度计
- 储粮害虫检查：昆虫轮廓
- 扦样分样：扦样器
- 水分杂质测定：烧瓶或水滴

### 7.2 实操详情

实操详情包含：

- 稻穗照片头图
- 作业目的
- 作业准备
- 操作步骤
- 安全提示
- 常见错误
- 关联练习

稻穗照片正式开发时保存为本地静态资源，不依赖远程 URL，并记录素材来源和许可。

## 8. 我的

“我的”只展示属于个人中心的内容：

- 头像和昵称
- 会员入口
- 累计练习、正确率、连续学习天数
- 今日目标
- 近七天学习情况
- 学习报告入口
- 编辑资料
- 学习设置
- 数据管理
- 意见反馈

首页已有错题本和收藏入口，因此“我的”首页不再重复放置大面积“复习”板块。错题本和收藏试题仍为独立二级页面。

## 9. 视觉设计系统

### 9.1 日间配色

- 页面背景：`#F4F6EE`
- 卡片背景：`#FFFFFF`
- 主文字：`#11120F`
- 选项正文：`#272D23`
- 辅助文字：`#71776C`
- 柠绿色：`#B8EC32`
- 选中浅绿：`#DFF58F`
- 危险色：低饱和红，禁止大面积高亮红

### 9.2 夜间配色

- 页面背景：`#151911`
- 卡片背景：`#20261B`
- 次级卡片：`#2B3422`
- 主文字：`#F0F2EB`
- 选项正文：`#E9EDE3`
- 辅助文字：`#A7AD9F`
- 夜间强调色：`#A8D63C`
- 夜间选中底色：`#33431F`

夜间模式不使用纯黑和纯白，避免过强对比。夜间模式应用于答题、答题卡和解析等答题相关页面。

### 9.3 形态

- 超大圆角哑光卡片。
- 微弱阴影，只用于层级区分。
- 不使用粗描边、发光效果、大面积渐变或玻璃拟态。
- 使用系统字体，不引入装饰字体。
- 保留大量留白，但目录和个人信息页面不得显得空洞。
- 所有业务图标使用统一线宽的 SVG 或小程序图标组件。

### 9.4 行业元素

- 使用简约筒仓、粮仓、稻穗和麦穗线稿。
- 装饰元素保持低透明度，不遮挡正文。
- 实操头图可使用真实稻穗照片。
- 不使用机器人、星光、通用 AI 插画或 AI 风格文案。

## 10. 答题选项组件

### 10.1 视觉

选项保持已确认的原稿样式：

- 默认选项为白色大圆角卡片，无粗描边。
- 字母标记为正圆。
- 默认字母标记使用奶绿色底和深绿色字母。
- 选中后整行使用浅柠绿色，字母圆形变为柠绿色。
- 提交前不增加对勾、正确或错误图标。
- 底部确认按钮未选择时为灰色；日间选择后变为黑色，夜间选择后使用降低亮度的柠绿色。

正式小程序建议值：

- 选项正文：`28rpx`
- 中文字重：`600`
- 行高：`1.5`
- 字母圆形：`56rpx`
- 单个选项可点击高度：不小于 `96rpx`
- 选项圆角：`32rpx` 至 `36rpx`

四个选项使用相同字重。选中状态只通过底色表达，不通过额外加粗暗示答案。

若部分 Android 系统字体对 `600` 支持不完整，允许回退到 `500`，但必须在真机上确认可读性，不得回退到常规 `400`。

### 10.2 状态机

单选题状态：

1. `idle`：所有选项中性，确认按钮不可用。
2. `selected`：仅突出用户当前选择，不显示答案。
3. `submitted-correct`：正确选项使用浅绿状态，其余选项锁定弱化。
4. `submitted-wrong`：用户错误选项使用低饱和淡红，正确选项使用浅绿，其余选项锁定弱化。

只有答错提交后，绿色正确项和红色错误项才同时出现。

模拟考试在交卷前始终保持 `selected` 视觉，不进入提交后状态。

### 10.3 选择动效

- 按下：选项缩放至约 `98.2%`，持续约 `100ms`。
- 松开：浅柠绿色在约 `200ms` 内从左向右铺开。
- 字母圆形：约 `300ms` 轻微回弹。
- 确认按钮：从灰色平滑过渡为黑色。
- 切换选项：旧选项恢复白色，新选项播放一次动效。

动效只表达“已选择”，不得提前暗示答案正确性。

## 11. 收藏动效

答题页收藏按钮位于顶部操作区：

- 未收藏：白色按钮、黑色线性星形。
- 已收藏：黑色按钮、柠绿色实心星形。
- 按下缩放约 `88%`。
- 星形回弹约 `420ms`。
- 外圈进行一次低透明度扩散。
- 底部状态提示约 `1.6s` 后消失。
- 再次点击取消收藏并显示取消提示。

正式小程序可调用受保护的轻触震动反馈；震动失败不得影响收藏业务。

## 12. 夜间护眼模式

答题页顶部提供月亮/太阳切换按钮：

- 月亮表示可开启夜间模式。
- 夜间模式下切换为太阳图标。
- 切换时页面颜色在约 `300ms` 内过渡。
- 切换后显示底部状态提示。
- 用户选择保存在本地偏好中，下次进入答题相关页面自动沿用。

主题偏好必须通过统一主题服务或偏好 Repository 读写，页面不得自行创建零散存储键。

夜间模式是舒适性辅助功能，界面文案不得宣传为医学护眼能力。

## 13. 二级交互与异常状态

### 13.1 交卷确认

交卷弹窗必须显示：

- 已答题数量
- 未答题数量
- 交卷后不可修改的说明
- “继续检查”
- “确认交卷”

### 13.2 空状态

错题本、收藏试题和筛选无结果时：

- 使用语义化图形。
- 解释为什么为空。
- 提供下一步操作。
- 不只显示“暂无内容”。

### 13.3 加载与网络

- 首次加载使用骨架屏，避免内容跳动。
- 网络异常说明已完成答案是否保存在本机。
- 提供“重新加载”。
- 本地题库可用时优先继续离线练习。

### 13.4 题目纠错

纠错类型：

- 题干错误
- 答案错误
- 解析不清
- 其他问题

提交后显示成功提示，不影响当前答题进度。

## 14. 组件与代码结构

优先重构或新增：

- `components/page-header`
- `components/icon-button`
- `components/certificate-selector`
- `components/question-option`
- `components/theme-toggle`
- `components/feedback-toast`
- `components/empty-state`
- `components/analysis-panel`

职责边界：

- 页面只负责生命周期、事件转发和视图组合。
- 练习和主题状态由 Service/Repository 管理。
- 视图状态转换放在 Presenter 或纯函数中。
- 页面不得直接读取题库 JSON 或直接调用 `wx.setStorageSync`。
- 颜色、圆角、阴影、字号和动效时长统一定义在 `styles/tokens.wxss`。
- 图标不得以单字文本临时代替。

## 15. 兼容与迁移

- 保留现有练习记录、错题、收藏和会话存储结构。
- 新增主题偏好时提升存储 schema 版本并增加迁移。
- 删除“题库”底部导航后，旧题库路由应兼容跳转到首页目录区域或新的教材目录页。
- 旧会话恢复后仍进入正确的职业、等级和章节。
- 现有题库 ID、章节 ID 和题目 ID 不因 UI 重构而修改。

## 16. 测试策略

测试驱动实现以下行为：

1. 底部导航只生成首页、实操、我的三项。
2. 职业和等级切换后目录与练习条件同步。
3. 五等级展示，缺少题库的等级返回“待补充”。
4. 单选题状态只允许一个未提交选择。
5. 提交正确时不出现红色错误选项。
6. 提交错误时只标记一个用户错误项和正确项。
7. 模拟考试交卷前不显示答案状态。
8. 收藏切换正确写入本地记录。
9. 夜间主题偏好保存并恢复。
10. 旧存储数据迁移后仍可读取。

界面验证覆盖：

- 首页进入章节练习
- 随机练习
- 模拟考试
- 答题卡
- 普通练习即时解析
- 交卷结果
- 错题重练
- 收藏切换
- 夜间模式切换
- 实操详情
- 我的页面和学习设置

## 17. 验收标准

1. 底部仅出现首页、实操、我的三个导航。
2. 首页完成题库选择、学习入口和教材目录摘要的合并。
3. 保管员和质检员均可先选职业再选五个等级。
4. 教材目录与当前职业、等级正确联动。
5. 所有二级页左上角均有可用返回按钮。
6. 实操图标全部为语义化图形，没有文字占位图标。
7. 答题选项符合白色圆角卡片、圆形字母和浅柠绿选中样式。
8. 选项正文在日间和夜间均清晰可读。
9. 选择、收藏和主题切换动效均克制且不影响操作。
10. 夜间模式可切换、保存和恢复。
11. 错题解析包含正确答案、解释、知识点和易错提示。
12. TypeScript、ESLint、Stylelint、Vitest 和题库验证全部通过。
13. 微信开发者工具无编译错误，主要流程可完成。
