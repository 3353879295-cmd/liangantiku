# 粮油仓储与质检刷题库建设设计

日期：2026-07-22
状态：用户已确认设计

## 1. 目标

建设一套可持续扩充、可追溯、可审核并可直接导入微信小程序的粮食行业刷题库。题库不设固定题量上限，以公开资料能够支持、答案能够核验、内容能够合法使用为收录前提；每累计约 1000 道审核合格题目形成一个可交付版本。

题库覆盖两个职业方向和三个技能等级：

| 职业名称 | 工种/职业方向 | 职业编码 | 等级 |
| --- | --- | --- | --- |
| 仓储管理员 | 粮油保管员 | 4-02-06-01 | 五级/初级工、四级/中级工、三级/高级工 |
| 农产品食品检验员 | 粮油质量检验员 | 4-08-05-01 | 五级/初级工、四级/中级工、三级/高级工 |

## 2. 非目标

- 不获取、破解或传播受保密管理的国家正式题库。
- 不绕过登录、付费、验证码或其他访问限制抓取资料。
- 不大批量照录单一网站、付费教材或第三方小程序的题目。
- 不把无法核验答案、来源失效或适用标准过期的题目发布到正式库。
- 第一阶段不建设微信小程序界面；本设计仅覆盖题库生产、审核和导出。

## 3. 建设方案

采用“公开资料收集 + 标准核验 + 去重改写 + 原创补充”的混合方案。

### 3.1 来源优先级

1. 国家职业技能标准、现行法律法规、国家标准和粮油行业标准。
2. 国家粮食和物资储备局等主管部门公开的竞赛文件、培训资料和操作技能考试手册。
3. 出版机构公开的教材目录、样章、试读内容和配套练习说明。
4. 高校、职业院校、行业协会及公开课程发布的教学资料和练习题。
5. 其他无需登录即可访问的公开练习题，仅作为知识线索，不直接采信其答案。

### 3.2 核心依据

- [（粮油）仓储管理员国家职业技能标准（2019 年版）](https://www.osta.org.cn/api/sys/downloadFile/decrypt?fileName=4eNsZIOv3WFNDfbnldJHeA%2F2024%2F4%2F29%2Fcb5d22fdcbfa44a3b85768b2b875a024.pdf)
- [农产品食品检验员国家职业技能标准（2019 年版）](https://chinajob.mohrss.gov.cn/upload/resources/jnbzpdf/4ccc6a76ab6420078c8b03.pdf)
- [粮油保管员职业技能操作考试手册](https://www.lswz.gov.cn/html/czjnkssc/2018-06/12/content_214443.shtml)
- [粮油质量检验员职业技能操作考试手册](https://www.lswz.gov.cn/html/czjnkssc/2018-06/12/content_214442.shtml)
- [国家题库粮食行业分库试题资源保密通知](https://www.lswz.gov.cn/html/bzjctk/2018-06/12/content_213891.shtml)
- [现行粮油行业标准目录](https://www.lswz.gov.cn/html/ywpd/bzzl/2024-01/26/content_275402.shtml)

来源目录需要记录资料标题、发布机构、链接、发布日期、抓取日期、有效性、版权使用方式和备注。任何题目进入正式库之前都必须能够关联至少一条来源记录。

## 4. 题库生产架构

题库生产过程划分为六个边界清晰的组件：

1. **来源目录**：登记来源元数据和有效性，不保存未经许可的大段版权原文。
2. **原始资料区**：保存公开题目线索、知识点摘记和待处理状态，仅供内部整理。
3. **规范化处理器**：统一职业、等级、题型、选项、答案和知识模块格式。
4. **去重与相似检测器**：处理完全重复、轻微改写和同知识点过密题目。
5. **核验与审核区**：核对答案、解析、标准版本和等级归属，管理审核状态。
6. **发布导出器**：仅从已核验记录生成 Excel 审核主库和小程序 JSON 数据。

组件之间只通过结构化题目记录和来源编号交换数据。原始资料区、待复核区与正式发布区相互隔离，避免未核验题目进入小程序。

## 5. 数据流

1. 搜索并登记公开来源。
2. 从来源中提取知识点或公开练习题线索。
3. 将内容规范化为候选题记录。
4. 对候选题进行完全重复和相似度检查。
5. 依据现行标准核验答案与解析，必要时重新编写题干和干扰项。
6. 标注职业、等级、知识模块、题型和难度。
7. 通过规则校验后进入待审核区。
8. 完成内容复核并标记为“已核验”。
9. 从已核验记录生成 Excel、JSON 和统计报告。
10. 标准变化或发现争议时，将受影响题目改为“待复核”或“已停用”，后续版本不再发布。

## 6. 题目数据模型

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| `id` | 题目唯一编号 | 全局唯一且发布后保持稳定 |
| `occupation_code` | 职业编码 | `4-02-06-01` 或 `4-08-05-01` |
| `occupation_name` | 职业名称 | 采用现行正式名称 |
| `direction` | 工种/职业方向 | 粮油保管员或粮油质量检验员 |
| `level` | 技能等级 | `5`、`4` 或 `3` |
| `module` | 一级知识模块 | 必填，使用受控词表 |
| `topic` | 二级知识点 | 必填，使用受控词表 |
| `type` | 题型 | `single`、`multiple` 或 `judge` |
| `stem` | 题干 | 表意完整，不依赖未提供的上下文 |
| `options` | 选项 | 单选/多选为 4 项，判断题为固定两项 |
| `answer` | 正确答案 | 必须与选项键匹配 |
| `explanation` | 答案解析 | 说明正确原因，必要时说明错误选项 |
| `difficulty` | 难度 | `easy`、`medium` 或 `hard` |
| `keywords` | 检索关键词 | 字符串数组，可为空数组 |
| `source_ids` | 来源编号 | 至少 1 项 |
| `standard_reference` | 标准或条款依据 | 有明确条款时必须填写 |
| `source_note` | 来源使用说明 | 区分知识依据、公开样题或原创补充 |
| `review_status` | 审核状态 | `verified`、`pending` 或 `retired` |
| `valid_from` | 内容适用起始日期 | ISO 日期 |
| `valid_until` | 内容适用截止日期 | 可为空 |
| `duplicate_group` | 相似题组编号 | 无相似题时为空 |
| `content_version` | 内容版本 | 语义变更时递增 |
| `created_at` | 创建时间 | ISO 时间 |
| `updated_at` | 更新时间 | ISO 时间 |

## 7. 分类与分级

### 7.1 粮油保管员

- 职业道德、法律法规和安全生产
- 粮油商品与储藏基础
- 仓房、油罐及设施设备管理
- 粮油出入库和账卡管理
- 粮温、湿度、水分、气体和品质检查
- 储粮害虫、鼠雀、霉变和发热识别
- 通风、降温、降水、气调和熏蒸
- 异常粮情分析与处置

### 7.2 粮油质量检验员

- 职业道德、法律法规和实验室安全
- 扦样、分样和样品制备
- 试剂、溶液、玻璃器皿和仪器使用
- 粮食、油料及制品质量指标
- 容量法、重量法、比色法和仪器分析基础
- 粮油储存品质和食品安全指标
- 数据处理、精密度、结果判定和质量控制
- 检验原始记录、报告编制与异常处理

### 7.3 等级差异

- 五级/初级工：侧重概念识记、基础规范、设备识别和在指导下完成常规操作。
- 四级/中级工：侧重独立完成常规任务、结果判断、一般异常识别和处理。
- 三级/高级工：侧重综合分析、方案选择、复杂异常处置、质量控制和设备故障分析。

题目不得仅通过替换等级标签重复使用。跨等级共通知识可以保留，但题干情境、认知要求和解析深度必须体现等级差异。

## 8. 题型与难度分布

以每个职业、每个等级的已核验题目为统计单元，目标分布为：

- 单选题约 60%。
- 多选题约 20%。
- 判断题约 20%。

允许单批次存在不超过 5 个百分点的偏差，累计版本应逐步回归目标比例。操作技能内容改编为可在小程序内完成的情景题，不宣称其等同于线下实操考核。

难度随等级递进。每个等级内部仍保留易、中、难题，避免把技能等级直接等同于题目难度。

## 9. 去重规则

- 规范化题干和选项完全相同的记录只保留一题。
- 仅调整语序、数字格式或选项顺序的题目归入同一相似题组。
- 同一知识点、相同考查角度和相同答案逻辑的题目原则上只保留表达最佳的一题。
- 同一知识点可以保留不同等级或不同应用场景的题目，但必须体现不同认知任务。
- 相似度检测只负责提出候选，最终保留或合并决定需要记录审核理由。

## 10. 核验与错误处理

题目状态采用三态管理：

- `verified`：答案、解析、来源和等级已经核验，可以发布。
- `pending`：存在来源、答案、版本或分类疑问，不得发布。
- `retired`：曾经发布但已过时、失效或确认有误，保留审计记录但不再导出。

自动校验至少覆盖：

- 必填字段完整性。
- 选项键唯一性及答案与选项的一致性。
- 单选题只有一个答案，多选题至少两个答案，判断题使用固定答案。
- 职业编码、等级、题型、难度和审核状态属于允许值。
- 已核验题至少关联一个有效来源。
- `valid_until` 不早于 `valid_from`。
- 正式发布数据中不存在完全重复题。

若来源链接失效，题目不立即删除；先根据来源存档、其他权威来源和标准条款复核。无法重新确认时转为 `pending`。若标准修订，按来源编号和标准条款批量定位受影响题目，完成复核前停止发布。

## 11. 版权与合规边界

- 对法规、标准和主管部门文件记录准确名称与链接，并按允许范围引用必要知识点。
- 对教材、课程、网站和第三方题库只使用其公开信息作为知识线索；题干、选项和解析需要重新组织表达。
- 不把“来源可访问”等同于“允许整库复制”。来源目录必须记录使用方式。
- 不把整理后的题库宣传为官方国家题库、官方真题或考试原题。
- 若后续取得某一来源的明确授权，可单独记录授权范围和期限，再决定是否保留原题表达。

## 12. 交付物

### 12.1 Excel 审核主库

工作簿包含以下工作表：

1. `正式题库`：仅包含 `verified` 题目。
2. `来源索引`：来源元数据、有效性和使用方式。
3. `待复核题`：所有 `pending` 题目及待处理原因。
4. `停用题`：所有 `retired` 题目及停用原因。
5. `题量统计`：按职业、等级、模块、题型、难度和状态汇总。

### 12.2 JSON 发布数据

JSON 按“职业编码 + 等级”拆分为六个文件。发布文件只包含小程序运行所需字段，不包含内部审核备注；来源编号和标准依据保留，以支持解析页展示和问题追踪。

### 12.3 版本报告

每批报告记录：新增题数、累计题数、各分类分布、去重数量、待复核数量、停用数量、来源增量和已知限制。

## 13. 验收标准

每个批次必须同时满足以下条件才能交付：

- 正式题库中的题目全部为 `verified`。
- 正式题库的必填字段完整率为 100%。
- 答案与选项格式校验通过率为 100%。
- 完全重复题数量为 0。
- 每道正式题至少关联一个有效来源。
- Excel 统计值与正式题库实际记录数一致。
- 六个 JSON 文件均可被标准 JSON 解析器读取，记录数与 Excel 对应职业等级一致。
- 随机抽查题目的职业、等级、答案、解析和来源能够相互对应。
- 交付报告明确列出本批次仍处于待复核或停用状态的内容数量，但这些内容不得混入发布数据。

## 14. 后续实施边界

实施计划需要依次完成数据目录与词表、来源清单、采集与规范化工具、去重和校验工具、Excel/JSON 导出、首批题目整理以及验收报告。题库按批次迭代，每批完成验收后再扩大来源范围和题量。
