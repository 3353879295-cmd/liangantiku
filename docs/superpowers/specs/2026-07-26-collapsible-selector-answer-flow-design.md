# 题库收缩与粉笔式答题流程设计

## 目标

在不新增、复制、拼接或生成题目的前提下，完成三项连贯体验：

1. 首页题库选择器在选定职业与等级后自动收起，并可随时重新展开。
2. 答题页支持左右滑动切换上下题，同时保留按钮作为无障碍备用入口。
3. 学习设置支持“即时解析”和“交卷后解析”，交卷后可以从答题卡逐题查看解析。

## 全局约束

- 题库保持现有 61 道 verified 题，不改变题目 ID、目录 ID、职业编码或实际题量。
- 随机练习仍只从真实候选题中抽取；不足 10 题时使用“全部 N 题”。
- 主导航仍只有“首页、实操、我的”。
- 模拟考试始终交卷后解析，不受普通练习偏好影响。
- 所有设置保存在本机；清除学习记录时保留用户偏好。
- 微信开发者工具、模拟器和真机验收只有实际执行后才能标记通过。

## 首页题库选择器

### 展开状态

- 保留两层结构：先选择报考职业，再选择该职业的五个证书等级。
- 切换职业只更新等级列表，不自动收起。
- 选定具体等级后更新当前题库，并自动切换为收起状态。
- 待开放等级仍可展示和选择，但不会生成题目；开始学习时继续显示题库待补充提示。

### 收起状态

- 使用一行紧凑摘要展示当前选择，例如“粮油仓储管理员 · 中级”。
- 右侧展示“重新选择”和向下箭头。
- 点击摘要任意区域重新展开。
- 展开与收起采用约 200ms 的透明度和纵向位移动画。
- 收起只影响当前首页界面，不改变证书数据或题库库存。

## 答案与解析设置

新增解析偏好：

```ts
export type AnswerRevealMode = 'immediate' | 'deferred';
```

学习设置增加“答案与解析”卡片：

- `immediate`：即时解析，选完后判题并显示答案。
- `deferred`：交卷后解析，答题过程中只保存选择，不显示正误或解析。

默认值为 `immediate`，以保持现有普通练习习惯。

### 会话锁定

- 开始一次练习时读取当前偏好，并写入练习会话。
- 模拟考试无条件写入 `deferred`。
- 练习开始后修改学习设置，只影响下一次练习。
- 持久化会话同时保存本次解析模式，恢复练习后规则不变化。

## 题型交互

### 即时解析

- 单选题、判断题：点击选项后立即提交当前题、判题并显示解析。
- 多选题、多答案案例题：允许切换多个选项，点击“确认答案”后判题并显示解析。
- 已显示解析的题目不可修改答案。
- 已答或未答题目都可以左右滑动离开。

### 交卷后解析

- 每次点选都立即保存到本次会话。
- 单选题再次点选其他选项时替换原选择。
- 多选题再次点选时切换该选项。
- 交卷前可以返回任意题修改。
- 过程中不显示正确答案、红绿状态或解析。
- 最后一题的主要操作进入答题卡，由答题卡统一交卷。

## 左右滑题

### 手势规则

- 左滑进入下一题，右滑进入上一题。
- 只在题目内容区域监听手势，不在固定顶部栏和底部操作栏监听。
- 横向位移必须超过固定阈值，并明显大于纵向位移，才识别为切题。
- 上下阅读长题或解析时不触发切题。
- 第一题右滑、最后一题左滑不循环，只展示轻微回弹反馈。
- 切题动画为 160–180ms，方向与手势一致。
- 切换完成后滚动到题目顶部。
- 动画未完成时忽略重复滑动。

### 备用操作

- 底部保留“上一题”和“下一题”按钮。
- 最后一题在未交卷状态显示“答题卡”。
- 交卷后的只读状态同样保留上下题按钮。

## 交卷后查看解析

1. 用户从答题卡提交本次练习。
2. 提交后进入成绩结果页。
3. 结果页提供“查看答题卡”入口。
4. 已提交答题卡使用绿色、红色、灰色区分正确、错误、未答。
5. 点击题号进入对应题目的只读解析状态。
6. 只读解析展示用户答案、正确答案、题目解析、知识点、易错原因和标准依据。
7. 用户可以左右滑动或使用按钮连续查看整套试题。
8. 已提交会话不能修改答案。

## 数据与迁移

本地学习数据升级到下一 schema 版本：

- `ProgressPreferences` 增加 `answerRevealMode`。
- `PersistedPracticeSession` 增加 `answerRevealMode`。
- 旧偏好迁移为 `immediate`。
- 旧模拟考试会话迁移为 `deferred`。
- 其他旧练习会话迁移为 `immediate`，保持原有反馈行为。
- 非法偏好安全恢复为 `immediate`。
- 迁移继续使用现有备份与恢复机制，不丢失答案、错题、收藏或练习进度。

## 代码边界

- `certificate-selector`：只负责展开、收起、职业与等级选择及摘要展示。
- `ProgressService`：读取和更新默认解析偏好。
- `practice-session`：保存会话解析模式，决定何时产生 feedback，提交后统一评分。
- `practice-swipe-presenter`：纯函数判断手势方向、阈值和首尾边界。
- `practice` 页面：协调选项、手势、动画、切题和只读状态，不复制评分逻辑。
- `answer-sheet` 与 `report`：复用同一会话，负责交卷和解析入口。

## 异常与边界

- 无有效练习时显示返回首页入口。
- 只有一道题时禁用切题手势。
- 未答题允许跳过，并在答题卡显示为未答。
- 交卷后所有选择入口禁用。
- 恢复会话时题目缺失继续使用现有裁剪或恢复策略。
- 无效解析偏好恢复为 `immediate`，不阻断应用启动。

## 自动验证

- 题库选择器展开、选择后自动收起、重新展开及待开放等级。
- 解析偏好持久化、清除学习数据后保留及旧 schema 迁移。
- 即时模式下单选/判断自动判题，多选确认后判题。
- 交卷后模式下选择持久化、跨题恢复、交卷前可修改、交卷后锁定。
- 模拟考试始终使用 `deferred`。
- 手势阈值、纵向防误触、方向、单题和首尾边界。
- 结果页进入已提交答题卡，答题卡进入指定题只读解析。
- 题库同步后仍为 61 道 verified 题、61 个唯一题目 ID、84 个唯一目录 ID和两个既有职业编码。

## 非目标

- 不增加题目、假解析或新职业等级内容。
- 不修改现有三主导航。
- 不增加联网账号同步。
- 不在本次改造中重写题库或评分算法。
