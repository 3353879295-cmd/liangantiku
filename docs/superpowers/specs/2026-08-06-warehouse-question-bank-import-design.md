# 保管员五等级题库导入设计

日期：2026-08-06

状态：用户已确认

## 目标

将 `D:\桌面\储备粮\保管员` 中的保管员资料整理为正式题库，完整覆盖初级、中级、高级、技师和高级技师五个等级；本轮不处理粮油质量检验员方向。

## 等级映射

| 资料等级 | 系统等级 | ID 前缀 | 前端名称 |
| --- | ---: | --- | --- |
| 初级 | 5 | `WH-L5` | 初级保管员 |
| 中级 | 4 | `WH-L4` | 中级保管员 |
| 高级 | 3 | `WH-L3` | 高级保管员 |
| 技师 | 2 | `WH-L2` | 保管员技师 |
| 高级技师 | 1 | `WH-L1` | 保管员高级技师 |

等级来自文件名和资料标题，不从题干推断；跨等级合订资料只在能够明确归属时导入，否则标记为待审。

## 数据流

原始 DOCX/PDF -> 只读抽取器 -> 规范化 JSONL -> Python 模型/分类/去重校验 -> `dist/json` 分片 -> 小程序运行时数据。

每道题保留来源文件、等级、题型、答案、解析和内容版本。无法可靠识别题干、选项或答案的记录不进入 `verified` 发布分片。

## 运行时范围

本轮活动题库只包含 `4-02-06-01` 保管员方向和五个等级。质检员方向的旧数据不参与新发布，也不出现在证书选择器中；后续接入时再按同一模型恢复。

## 验证要求

- 题目 ID 使用 `WH-L[1-5]-NNNNNN`。
- 题型与答案数量符合模型约束；判断题固定为 A=正确、B=错误。
- 五个等级均有独立分片，分片只包含对应等级。
- 题库中无重复 ID 和完全重复题；近重复只作为警告。
- 所有 `verified` 题目必须关联活动来源并有解析和标准依据。
- 构建后运行 Python 测试、数据校验、构建、同步脚本和小程序验证。
