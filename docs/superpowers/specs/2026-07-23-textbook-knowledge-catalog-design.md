# 《粮油保管员（第二版）》知识目录设计规格

**状态：** 已确认

**日期：** 2026-07-23

**适用范围：** 微信小程序“题库”中的仓储管理员知识目录、章节练习和小节练习

## 1. 目标

将现有按题目内容临时聚合的平铺知识模块，重构为以《粮油保管员（第二版）》原书目录为唯一标准的稳定知识目录。

仓储管理员目录采用“部分 → 章节 → 小节”三级结构，完整保留原书中的四部分、11 章和 44 节。目录节点不因当前题量不足而隐藏，以便后续按教材持续补充题目。

粮油质检员继续作为独立职业模块保留，使用自己的知识目录，不强行套用仓储管理员教材结构。

## 2. 等级范围

仓储管理员选择不同证书等级时，显示范围如下：

- 初级：第一部分“基础知识”＋第二部分“初级粮油仓储管理员”
- 中级：第一部分“基础知识”＋第三部分“中级粮油仓储管理员”
- 高级：第一部分“基础知识”＋第四部分“高级粮油仓储管理员”

默认不把低等级职业部分重复显示在高等级目录中。需要复习的前置内容通过题目的关联知识点表达，不改变目录等级归属。

## 4. 稳定目录编号

每个部分、章节和小节使用稳定、可读且与显示文案解耦的编号。

示例：

```text
warehouse-basic-c01-s01  职业道德基础知识
warehouse-l5-c03-s01     粮油出入库准备
warehouse-l4-c07-s02     检查储粮湿度和水分
warehouse-l3-c11-s06     防治储粮发热霉变
```

编号规则：

- `warehouse-basic` 表示三个等级共用的基础知识。
- `warehouse-l5`、`warehouse-l4`、`warehouse-l3` 分别表示初级、中级和高级。
- `cNN` 使用原书章号。
- `sNN` 使用对应章内的原书节号。
- 编号一经发布不得因文案调整或题量变化而改变。

## 5. 题目数据归属

仓储管理员题目新增稳定的章节和小节归属：

```ts
interface QuestionCatalogReference {
  chapterId: string;
  sectionId: string;
}
```

规则：

1. 每道仓储管理员题目必须归入 44 个标准小节之一。
2. `sectionId` 必须属于对应的 `chapterId`。
3. 题目等级必须与目录部分一致；基础知识允许适用于初级、中级和高级。
4. 题库发布时校验目录编号，无法确定归属的题目不得发布。
5. 不设置“其他”或“未分类”作为正式发布目录。
6. 现有 `module` 和 `topic` 字段在第一阶段保留用于兼容，业务筛选逐步迁移到 `chapterId` 和 `sectionId`。
7. 现有仓储管理员题目逐题人工映射；不能确定归属的题目进入审核清单，不根据关键词自动猜测。
8. 粮油质检员使用独立的稳定目录编号和校验规则。

## 6. 题库页面

仓储管理员题库页面使用三级目录：

1. 部分标题作为内容分组。
2. 章节行显示章号、章名、题量、完成进度、正确率和错题数。
3. 点击章节展开或收起小节。
4. 小节行显示节名、题量和学习状态。
5. 点击有题章节可练习本章全部题目。
6. 点击有题小节只练习该小节题目。
7. 无题章节和小节显示“待补充”，保留目录位置但不启动空练习。

界面继续采用现有 Apple 式浅色视觉，通过缩进、细分隔线和克制的状态颜色表达层级，不使用复杂树形图、装饰插画或 AI 风格文案。

粮油质检员页面采用相同的交互形式，但展示质检员自己的目录。

## 7. 练习、错题和统计

- 章节练习按 `chapterId` 筛选。
- 小节练习按 `sectionId` 筛选。
- 错题本和收藏可以按章节、小节筛选。
- 练习报告按标准章节聚合，并可进一步展示薄弱小节。
- 完成进度、正确率和错题数从题目 ID 与答题历史计算，不将聚合结果写死在目录中。
- 相同中文节名在不同等级下通过稳定编号区分，统计不得串级。

## 8. 本地数据兼容

现有错题、收藏、答题历史和练习会话均以题目 ID 为主键，目录重构不改变题目 ID，因此不清空现有学习数据。

未完成练习继续按原有题目 ID 列表恢复答案和当前位置。题库升级后缺失的题目仍沿用现有会话修复机制移除。

旧的中文 `module` 筛选只作为过渡兼容入口；新创建的章节和小节练习使用稳定目录编号。

## 9. 第一阶段范围

本阶段完成：

- 标准目录数据。
- 现有题目的目录归属。
- 题库页章节与小节入口。
- 按章、按节筛题。
- 目录计数及空目录状态。
- 相关自动化测试与微信开发者工具编译验证。

本阶段不包含：

- 复制或改写教材正文。
- 根据目录批量生成新题。
- 填满所有零题小节。
- 修改普通答题页的核心交互。
- 将粮油质检员并入仓储管理员目录。

## 10. 验收标准

1. 仓储管理员目录准确包含四部分、11 章和 44 节。
2. 章节、小节编号唯一且稳定，教材页码顺序正确。
3. 初级显示基础知识和初级部分，中级显示基础知识和中级部分，高级显示基础知识和高级部分。
4. 所有仓储管理员正式题目均归入有效小节，且等级与目录一致。
5. 章节练习和小节练习不会混入其他等级或职业的题目。
6. 题量为零的章节和小节仍显示，并明确标记“待补充”。
7. 粮油质检员仍可独立选择和练习。
8. 现有错题、收藏、答题历史和未完成练习无需清空即可继续使用。
9. 目录数据、筛选、聚合、兼容行为均有自动化测试覆盖。
10. TypeScript、ESLint、Stylelint、Prettier、Vitest 和微信开发者工具编译全部通过。
